# Dog sound library

Names are fixed by `SOUND_NAMES` in `app/src/shared/audio.ts`. Files are
`assets/sounds/<name>_<n>.mp3`, 2–3 variants each (`_1`, `_2`, `_3`).
Generated by `scripts/generate_sounds.mjs` (ElevenLabs Sound Effects, L1).

Priority: **P1** = generate first (credits may run short); **P2** = the rest.

| Name | Priority | Duration (s) | Loop | Prompt |
|---|---|---|---|---|
| `bark_happy` | P1 | 1 | no | A single bright, higher-pitched "woof" from a happy small-to-medium dog, energetic, jolly and playful, light and cheerful, not deep, growly or aggressive, clean dry recording, no background noise |
| `pant` | P1 | 3 | yes | A dog panting happily after running, steady rhythmic breathing, close microphone, no background noise |
| `snore` | P1 | 3 | yes | A sleeping dog snoring softly, slow deep breaths with a gentle rumble, no background noise |
| `ball_squeak` | P1 | 1 | no | A short, cute, playful rubber squeaky-toy squeak, one quick bright "squeak", soft and friendly, not harsh or shrill, clean dry recording, no background noise |
| `bark_alert` | P2 | 1 | no | A single bright, attentive alert bark from a friendly medium-sized dog, clear and playful, not aggressive or growly, clean dry recording, no background noise |
| `yip_excited` | P2 | 1 | no | Two quick excited high-pitched yips from a dog, playful, clean dry recording |
| `whine` | P2 | 2 | no | A soft short dog whine, curious and a little pleading, clean dry recording |
| `yawn` | P2 | 2 | no | A dog yawning with a small squeaky whine at the end, sleepy, clean dry recording |
| `sneeze` | P2 | 1 | no | A quick small dog sneeze, clean dry recording |
| `sigh` | P2 | 2 | no | A dog letting out a long contented sigh while settling down, clean dry recording |
| `paw_step` | P2 | 1 | no | Soft dog paws taking two quick steps on a hard surface, light claw taps |
| `ball_bounce` | P2 | 1 | no | A small rubber ball bouncing once on a hard floor, single clear bounce |

Notes
- Keep clips short (< 2 s) except `pant` and `snore`, which loop.
- After generating, listen to every variant; regenerate any that sound wrong.
- If credits run low: P1 sounds first, then reuse variants.
